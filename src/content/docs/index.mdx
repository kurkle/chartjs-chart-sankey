`chartjs-chart-sankey` is a Chart.js extension for rendering sankey diagrams.

## Installation

```bash
npm install chart.js chartjs-chart-sankey
```

## Basic Usage

Register the controller and the elements when using the ESM package entry. `NodeElement` is the element of a node; a chart also works when only the controller and `Flow` are registered.

```js
import { Chart } from 'chart.js'
import { Flow, NodeElement, SankeyController } from 'chartjs-chart-sankey'

Chart.register(SankeyController, Flow, NodeElement)
```
